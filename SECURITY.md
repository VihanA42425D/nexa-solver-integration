# Security

This repository is a public integration reference. It contains no private keys,
signing service, privileged RPC endpoint, or Nexa operational logic.

Never commit a private key or authenticated RPC URL. Before submitting a
transaction, independently verify the chain ID, contract bytecode, active-set
epoch, route witness, quote, deadline, token addresses, recipient, and value.

Security reports should be sent privately through the security contact listed
on the Nexa GitHub organization or account. Do not open a public issue for an
unpatched vulnerability.
